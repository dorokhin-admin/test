Данный проект выполнен в рамках тестового задания на вакансию HTML верстальщик.

Была выполнена верстка лендинга по макету из Figma с использованием чистого HTML CSS и JavaScript без применения фреймворков.

Добавлены hover состояния для интерактивных элементов.

Включен таймер обратного отсчета. В качестве референса использованы сервис sinoby timer. Логика таймера реализована на JavaScript.

Для всплывающих окон использована библиотека Fancybox 3. Реализована форма с полем ввода номера телефона и кнопкой отправки. Форма включает базовую обработку ввода номера телефона.

Проект адаптирован под мобильные устройства.

По времени затрачено два вечера по 3-4 часа

В процессе выполнения задания существенных затруднений не возникло.
